## 1. Federal Statutes

**File:** `server/data/federal-statutes-seed.ts`

**Primary source:** Cornell Legal Information Institute (LII) — https://www.law.cornell.edu/uscode

Statutory text is sourced verbatim from Cornell LII and stored in full (no truncation). Each entry carries `sourceApi: 'cornell_lii'` in the data schema.

**Statutes included:**

| Citation | Description |
|----------|-------------|

| 18 U.S.C. § 641 | Theft of Government Property |
| 18 U.S.C. § 1028 | Identity Theft |
| 18 U.S.C. § 1956 | Money Laundering |
| 18 U.S.C. § 2113 | Bank Robbery |
| 21 U.S.C. § 841 | Drug Possession with Intent to Distribute |

**Verification:** Quarterly automated URL check via `.github/workflows/quarterly-data-review.yml` → `check-federal-statutes.ts`. That script sends HTTP HEAD requests to each Cornell LII URL and flags redirects or errors for manual review.

**To update:** Visit the Cornell LII URL for each statute, compare to the stored text, and update `server/data/federal-statutes-seed.ts`. Statute text changes are rare but do occur when Congress amends a section.

## 2. Criminal Charges Database
**Public page:** `/data-sources` — Section §2 (Criminal Charges Database) and §8 (Jury Instruction References)

**File:** `shared/criminal-charges.ts`

**Total charges:** 7,155 (verified April 2026 against live file) — original base charges plus phases 1–5 as described below. Note: the earlier figure of 7,579 cited in March 2026 did not match the live file; the correct count from the search indexer and direct file analysis is 7,155.

**Phase breakdown:**
- Phase 1 (228 entries): Criminal attempt, conspiracy, aiding and abetting, accessory after the fact — MPC §§ 2.06, 2.07, 5.01, 5.03; federal 18 U.S.C. §§ 2, 3, 371
- Phase 2 (228 entries): Attempted murder, attempted robbery, attempted sexual assault, criminal solicitation — federal 18 U.S.C. §§ 373, 1113, 1951, 2242
- Phase 3 (285 entries): Sentencing enhancements — gang/RICO, hate crime, recidivist/three-strikes, firearm-in-felony, drug school zone — federal 18 U.S.C. §§ 249, 521, 924(c), 924(e), 1959; 21 U.S.C. § 860
- Phase 4 (117 entries): White-collar and federal-specific crimes — state RICO/racketeering and money laundering (56 jurisdictions each) plus federal-only entries for RICO (18 U.S.C. § 1962), money laundering (18 U.S.C. § 1956), drug trafficking (21 U.S.C. § 841), illegal entry (8 U.S.C. § 1325), illegal re-entry (8 U.S.C. § 1326)
- Phase 5 (225 entries): Juvenile-specific proceedings — delinquency adjudication (felony and misdemeanor level), transfer to adult court, juvenile firearm possession — all 56 jurisdictions plus federal (18 U.S.C. §§ 5031–5042); key cases: In re Gault (1967), Kent v. United States (1966), Miller v. Alabama (2012)

**Total as of 2026-04: 7,155 charges.** All phases cover 57 jurisdiction codes: 50 states + DC + AS/GU/MP/PR/VI (56 geographic jurisdictions) plus a separate `federal` code (19 charges).

**Two tiers of accuracy apply:**

| Tier | Charges | Accuracy approach |
|------|---------|-------------------|
| Base (original) | ~6,496 entries | Synthesized from MPC patterns; statute codes are generated placeholders, not pulled from state legislatures. Penalty ranges reflect common patterns. Do not cite statute numbers as authoritative without cross-referencing the actual state code. |
| Inchoate / derivative (Phase 1 & 2) | 456 entries | Grounded in universal legal doctrine (MPC §§ 2.06, 2.07, 5.01, 5.02, 5.03), which has been adopted substantially by nearly all states. Federal entries cite actual statutes (18 U.S.C. §§ 2, 3, 371, 1113, 1349, 1373, 1951, 2242). State `code` fields reference the MPC section rather than fabricating a state-specific number, which is accurate across all jurisdictions. |

**Important caveat (base charges):** The base charges contain synthesized statute codes used for consistency, not individual state legislature lookups. The file header contains this disclosure. Inchoate charges deliberately avoid this pattern by citing MPC doctrine instead.

- Charge categories and penalty ranges reflect common patterns across US jurisdictions
- Individual statute codes in the base set (e.g., "Cal. Penal Code § X") should be verified against the actual state code before being cited authoritatively
- This data powers the AI Case Guidance feature's charge classification and validation, not the static editorial pages

**Jury instruction overlay file:** `shared/criminal-charge-citations.ts` — a separate companion file that annotates select charges (primarily CA, NY, FL, TX, PA, OH, IL, and other major jurisdictions) with jury instruction references (`instructionRef`, e.g., "CALCRIM 1600") and direct URLs (`instructionUrl`) to court-hosted instruction documents. This file does not duplicate charge records; it overlays citation and instruction data onto charges defined in `shared/criminal-charges.ts`. Coverage is documented in `docs/citation-research/pji-availability.md`.

**References:** Model Penal Code (American Law Institute, §§ 2.06, 2.07, 5.01, 5.02, 5.03); 18 U.S.C. §§ 2, 3, 371, 1113, 1349, 1373, 1951, 2242; FBI Uniform Crime Reporting (UCR) classifications for charge frequency ranking.

**Live statute APIs:**

| API | Role | Status | Env var |
|-----|------|--------|---------|
| OpenLaws — https://docs.openlaws.us/ | **Tier 3 citation fallback** in the legal accuracy validator. When a citation from AI guidance is not found in the local DB, OpenLaws is queried as a live authoritative source before the citation is flagged as unverified. Covers all 50 states + federal (4.3M+ sections). | Active (fails silently if key absent) | `OPENLAWS_API_KEY` |
| GovInfo — https://api.govinfo.gov | Federal statute package search (metadata + document links, not full text). Used in `legal-data.ts` for `searchFederalStatutes()`. | Active | `GOVINFO_API_KEY` |
| LegiScan — https://api.legiscan.com/ | Bill tracking — monitors new criminal legislation across states for staleness detection. Not part of the guidance or validation pipeline. | Configured, not actively called | `LEGISCAN_API_KEY` |

**To update:** For a given state, cross-reference the synthesized charges against the state's current criminal code via its official legislature website. Any corrections to statute citations or penalty ranges should be applied in `shared/criminal-charges.ts`.

**California authority database:** `server/data/california-source-database-seed.ts`
and the `statute_sources`, `statute_source_snapshots`, `statute_charge_links`,
and `statute_ingestion_runs` tables store narrow, reference-only provenance for
the selectable California canonical records. The initial release does not
automatically crawl or copy California Legislative Information text because the
site's crawler policy disallows it. It stores official URLs, exact citations
and subdivisions, retrieval dates, effective-date evidence, and
`reference_metadata` SHA-256 fingerprints. Reference-only imports leave
retrieval/check timestamps null and record a separate manifest-import time;
they do not claim that a source was freshly retrieved or verified. Changed
references create a review queue entry and do not silently replace the
currently linked snapshot.
OpenLaws is explicitly excluded from this database's retrieval and fallback
paths. See `docs/citation-research/california-source-database.md`.

## 2c. Charge Explanations — Plain-Language Content
**Public page:** `/data-sources` — Section §2b (Charge Explanations)

**Files:** `shared/charge-explanations.ts` (60 charge-category entries) and `shared/charge-explanation-jurisdiction-overlay.ts` (per-jurisdiction detail, keyed `{state}-{slug}`)

**What this powers:** The "Understanding Your Charges" card on the case guidance dashboard and in the exported PDF — plain-language `plainSummary`/`keyTerms`/`degreeContext` per charge category, shown to users regardless of source. Until August 2026 this file had no sourcing at all; it was written by an AI coding agent with no citations and no methodology, and was not documented anywhere in this index. The gap was identified during an internal audit of whether the site could claim its content is "based on publicly available information." As of August 2026, that gap is closed for all three coverage tiers across every jurisdiction in scope except two disclosed gaps: South Dakota (blocked entirely, all three tiers) and Oklahoma (missing Tier 2 only, since its sourcing wall was resolved by the time Tier 3 reached it). No further tier is planned beyond Tier 3: the remaining 4 charge categories (see the coverage table below) are intentionally kept generic, not queued for future state-by-state work.

**Architecture:** `shared/charge-explanations.ts` holds one generic, cross-jurisdiction entry per charge category (60 total, regex-matched against the charge name), each carrying a stable `slug` (matching the `shared/criminal-charge-citations.ts` slug convention) plus its own `sources[]` / `dataConfidence` / `lastVerified` fields describing the generic prose. `shared/charge-explanation-jurisdiction-overlay.ts` is a separate overlay file, same pattern as `criminal-charge-citations.ts` overlaying `criminal-charges.ts`: real per-state structured detail (`citation`, `keyRule`, `penaltyClass?`, `source`, `sourceUrl?`, `dataConfidence`, `lastVerified`), joined at lookup time by `{state}-{slug}`. `getChargeExplanation(chargeName, jurisdiction?)` merges the two when a jurisdiction is provided and an overlay entry exists for that state; both dashboard and PDF call sites pass the user's jurisdiction. When no overlay entry exists for a state, the generic entry is shown alone — no regression, just no state-specific detail yet.

**Sourcing method:** Real statute text read directly from state legislature/government sites (primarily `leginfo.legislature.ca.gov`, `nysenate.gov`, `flsenate.gov`, `law.lis.virginia.gov`, `codes.ohio.gov`, `codes.findlaw.com`, `ncleg.gov`, `azleg.gov`), not a bulk API sweep — each entry is grounded in text actually read at generation time, with the citation itself usually already verified in `shared/criminal-charge-citations.ts` (so the "which statute" research is reused, not redone). OpenLaws was deliberately not used for this content: bulk automated querying risked the kind of high-volume API usage the vendor has previously objected to, and `server/services/openlaws-client.ts` also hard-requires a live `DATABASE_URL` to import, which isn't a given in every environment this content gets authored in.

**Expansion beyond the 10-state anchor set:** All 16 Tier 1 categories now also cover Texas (TX), Pennsylvania (PA), Michigan (MI), Washington (WA), Massachusetts (MA), Tennessee (TN), Indiana (IN), and Missouri (MO), bringing anchor+expansion coverage to 18 jurisdictions. Texas required more redirection than most anchor states: it has no "second degree murder," "battery," or standalone domestic violence statute (each folds into a related charge), calls its DUI equivalent "DWI" and defines it in the Penal Code rather than a motor vehicle code, and calls its top murder charge "capital murder" rather than "first degree." Pennsylvania's felony murder rule IS its entire second degree murder statute, it has no third degree burglary tier, and simple drug possession is a flat misdemeanor with no scaling by schedule or quantity. Michigan combines premeditated and felony murder into one first-degree tier and, unusually, requires no breaking to enter a dwelling but does require breaking for a non-dwelling building, the opposite of most states' pattern. Washington splits felony murder across two degrees by an enumerated-felony list, grades third degree assault as a felony rather than a misdemeanor, and treats simple drug possession as a flat gross misdemeanor following the state supreme court's 2021 Blake decision. Massachusetts is the strictest burglary statute surveyed so far: an actual breaking and entering of a dwelling specifically at night, carrying a minimum 10-year sentence; it also assigns the job of finding a murder's degree explicitly to the jury. Tennessee includes plain theft, not just robbery or burglary, on its felony-murder qualifying list; criminalizes overdose deaths from unlawful drug distribution as second degree murder; and inverts its own terminology, using "aggravated burglary" to mean burglary of a dwelling specifically rather than a weapon- or injury-based enhancement as in its other statutes. One Tennessee citation (domestic assault, § 39-13-111) had been flagged "repealed" by an earlier automated check in the underlying citation database; that flag was independently checked and confirmed incorrect during this pass. Indiana is the most structurally distinct state surveyed so far: it has no murder degree split at all (a single "murder" offense), and no "assault" crime separate from battery — every level of unwanted contact, from a rude touch to a life-threatening injury, is graded as battery under one statute; Indiana's burglary statute is also one of the few that still requires an actual breaking, not just unauthorized entry. Missouri's entire assault ladder is felony-only with no misdemeanor tier at all, its felony murder rule applies to a death during any felony rather than an enumerated list, and its theft statute ("stealing") grades primarily by specific item category (firearms, livestock, motor vehicles, financial-institution property) rather than a clean value ladder alone; Missouri's own statute site flags a pending technical re-numbering of its assault chapter effective July 1, 2027, which was checked against independent sources and does not appear to change the substance described here. Maryland has no third-degree assault tier and no standalone domestic violence crime (charged as second degree assault with a "domestically related" designation), splits DUI into four separate tiers rather than one BAC line (including a distinctly lighter "impaired by alcohol" tier below "under the influence"), and is the only state surveyed so far that scales drug possession penalties purely by prior convictions rather than by drug type, schedule, or quantity at all. Wisconsin required a significant real-time correction: its battery/assault statute was fully recodified from § 940.19 to § 940.60 by 2025 Wisconsin Act 24 (effective August 10, 2025), so this project's underlying citation index, which still cites the older § 940.19 numbering, is now stale for that entire statute family; the current § 940.60 citation was used instead and the discrepancy flagged for the sibling citation-verification project. Wisconsin also has no "assault" terminology at all (only graded battery, like Indiana), and its felony murder rule is structurally unique among all states surveyed: rather than a separately graded murder charge, it is a straight 15-year sentence enhancement added on top of the underlying felony's own maximum penalty. Colorado has its own distinctive throughline: sudden heat of passion does not create a separate lesser charge the way it does in most states surveyed; instead it simply lowers the felony class of the same second degree murder or assault charge. Colorado's felony murder rule also sits in second degree, not first, and its manslaughter statute has no heat-of-passion provision at all (repealed in 1996) — only reckless killing and assisted suicide. Minnesota required a real-time citation correction of its own: this project's underlying citation database pointed its "aggravated assault" entry to Minn. Stat. § 609.225, which was repealed by the Minnesota legislature in 1979 — the current § 609.221 (first degree assault) was substituted, and the discrepancy was flagged for the sibling citation-verification project. Minnesota also has genuine standalone domestic assault and deadly-weapon-assault statutes (each its own dedicated charge, not a redirect), a four-tier burglary system, and a DUI/drug-possession numbering quirk where the least-serious, most common charge is labeled "fourth degree" (DUI) or "fifth degree" (drug possession) rather than "first," the opposite of the usual convention. South Carolina has no degree split for murder at all (like Indiana), and its felony murder rule is not a separate charge or degree either — it is one of 12 statutory aggravating circumstances used only at capital sentencing. South Carolina's assault naming is also genuinely counterintuitive: its most serious tier is called "assault and battery of a high and aggravated nature" (ABHAN), not "first degree," and actually carries a harsher penalty than the statute's own literal "first degree" subsection. Two South Carolina entries (DUI and drug possession) rely on secondary sources after the official statute site's chapter pages didn't include the exact subsections needed, and are marked medium confidence pending a closer follow-up read. Alabama also has no degree split for murder (like Indiana and South Carolina), but unlike South Carolina its felony murder rule is a fully chargeable subsection of the same murder statute rather than a capital-sentencing-only aggravator. Alabama has no separate "aggravated assault," "assault with a deadly weapon," or "battery" statute at all; each is mapped to the relevant subsection of its three-tier assault scheme (first, second, and third degree). Alabama does have a genuine three-degree domestic violence statute, the second found after South Carolina, structured differently: the degree is set by which underlying offense (assault, stalking, or burglary) was committed against a qualifying victim, not by a separately defined set of elements; its first-degree citation had been flagged "needs_review" in the underlying citation database and was independently confirmed current and correctly cited during this pass. Alabama's robbery statute is unusually built backward: the numerically higher third-degree section defines the base offense, and first degree simply layers a weapon or serious injury on top of that base definition. Louisiana is the clearest surviving example of the traditional common-law assault/battery split found in this project: assault never requires touching and battery always does, and each side is independently graded (simple and aggravated assault; simple, second degree, and aggravated battery), so this project's underlying citation database's degree-numbered assault mappings for Louisiana (first/second/third degree assault pointed at aggravated battery, simple battery, and simple assault respectively) were kept as severity-based analogs rather than literal statute-name matches, and marked medium confidence accordingly. Louisiana also has two distinct felony-murder rules rather than one, a shorter list attached to second degree murder and a longer, more serious list attached to first degree, so which list a felony falls on determines the degree charged; its own "needs_review"-flagged second degree murder citation was independently confirmed current and correctly cited, the third such false-flag finding after Maryland and Alabama. Louisiana's armed robbery carries a 10-year mandatory minimum with no parole, probation, or suspension, comparable to South Carolina's mandatory floor. Kentucky is the first state surveyed with no felony murder concept in any form, not folded into another degree, not a sentencing aggravator, simply absent: the 1974 penal code recodification deliberately abolished it by statute, one of only a handful of states to do so, meaning a death during another felony in Kentucky must independently satisfy the state's intentional or wanton-extreme-indifference murder test rather than being automatically elevated. Kentucky also caught a genuine citation-index error, not a false "needs_review" flag this time: the project's underlying database had mapped "assault in the third degree" to KRS § 508.030, which is actually Kentucky's fourth degree (general-victim) assault statute; the real third degree statute (§508.025) is a protected-class statute covering peace officers, healthcare workers, and other public-facing workers on duty, and was substituted after independently confirming both statutes' text. Kentucky's first degree robbery and burglary statutes share a distinctive disaster-area enhancement, elevating the offense from a Class B to a Class A felony if committed within a declared emergency area during that emergency, not seen in any other state surveyed. Oregon has a rare three-tier homicide structure: "aggravated murder" (the only capital-eligible tier) sits above "murder in the first degree," which is not its own standalone definition but simply second degree murder elevated by aggravating circumstances, which in turn sits above the base "murder in the second degree" tier that actually contains the felony murder rule. Oregon's drug possession law required particular care: 2020's Measure 110 decriminalized small-quantity possession to a non-arrestable violation, and 2024's House Bill 4002 (effective September 1, 2024) repealed that and created a new possession misdemeanor with a pre-booking deflection option, but several cached secondary sources for the relevant statute (ORS 475.752) still reflect stale pre-2024 or even pre-Measure-110 penalty language; the entry here is marked medium confidence rather than risk propagating outdated penalty text, and flags the discrepancy explicitly rather than guessing at the exact current subsection number. Oklahoma required unusually heavy real-time verification: its felony sentencing was overhauled statewide by the Oklahoma Sentencing Modernization Act (HB 1792), effective January 1, 2026, which sorted most felonies into new Class Y/A/B/C/D tiers, confirmed directly in current statute text for several entries (first degree murder is explicitly "Class Y," manslaughter is "Class A2"/"Class B5," several assault offenses are "Class B2"/"Class B4"). Oklahoma also does not use numbered assault-degree terminology at all, instead using a patchwork of named offenses (assault and battery, assault/battery with a dangerous weapon, aggravated assault and battery) plus a separate three-tier domestic abuse statute; this project's underlying citation database had mismapped the numbered assault-degree slugs to subsections of that domestic-abuse statute specifically, a genuine error (not a false "needs_review" flag) corrected here by pointing those entries to Oklahoma's actual general assault statutes instead. Oklahoma is also the second state surveyed, after Louisiana, with genuinely separate assault and battery definitions. Oklahoma's felony murder rule splits across both murder degrees by which felony list applies, the same structural pattern as Louisiana and Texas. Oklahoma's DUI law changed very recently too: Senate Bill 54, effective November 1, 2025, made "aggravated DUI" a felony even on a first offense when an aggravating factor is present, a departure from the first-offense-is-always-a-misdemeanor pattern every other state surveyed follows. Connecticut has no true murder-degree split either, and surfaced a genuine mapping inversion in this project's underlying citation database: the "second degree murder" citation for Connecticut actually points to a MORE serious elevated tier ("murder with special circumstances," an eight-factor list including killing a police officer or a victim under 16), not a lesser second-degree offense as the label would suggest; that entry was corrected to point to the same base murder statute as first degree instead, with the inversion documented explicitly rather than silently followed. Connecticut keeps felony murder as a fully separate, third homicide statute (distinct from both base murder and the special-circumstances tier), and is one of the most weapon-mandatory-minimum-heavy states surveyed: robbery, burglary, and first degree assault each carry their own 5-year non-suspendable minimums for their armed-weapon paths specifically. Connecticut also has the most finely graded theft ladder found in this project, six numbered degrees from $20,000+ down to under $500. Utah's top homicide tier is also called "aggravated murder" rather than "first degree," the same naming pattern as Ohio and Oregon, with the longest felony-murder predicate list of any state surveyed (24 offenses) living in its base murder tier rather than the aggravated one. Utah caught two genuine citation-index mismappings in this pass: "burglary in the first degree" had been pointed to Utah's base burglary statute, which tops out at only a second degree felony even for a dwelling, when the actual first-degree-equivalent is a separately named "aggravated burglary" statute; and the felony-theft grading citation had been pointed to an unrelated theft section rather than the actual classification statute (§76-6-412). Utah has the lowest per se DUI BAC threshold of any state surveyed by a wide margin, 0.05% rather than the 0.08% used everywhere else in this project, after becoming the first state in the nation to adopt that lower limit in 2018. Nevada, like Louisiana and Oklahoma before it, keeps genuinely separate assault (threat, no contact) and battery (actual force) statutes, and is unusual in having a genuine dedicated domestic violence battery statute rather than a definitions-only procedural section, breaking a run of several prior states with no standalone crime. Nevada is also the only state surveyed with a completely ungraded robbery statute, no first/second degree split at all, with weapon use instead triggering a stacked sentencing enhancement, and treats simple drug possession as a felony from the first offense (its lowest felony category is generally probation-eligible), rather than a misdemeanor as in most states surveyed. Nevada's assault/battery statutes (NRS 200.471/200.481) recently split into two effective versions, one through June 30, 2026 and a new one effective July 1, 2026; several entries reflect the newer version but could not be independently confirmed against its full text, so they are marked medium confidence pending a closer follow-up read, the same disclosure pattern used for other recent-law-change states in this project. Iowa's felony murder rule is structurally distinct from every other state surveyed: rather than an enumerated list written directly into the murder statute, it is tied to a separately defined statutory term, "forcible felony" (child endangerment, assault, murder, sexual abuse, kidnapping, robbery, human trafficking, first degree arson, first degree burglary), with several offenses specifically carved OUT of that definition, including simple assault and domestic abuse assault. Iowa's single "assault" statute is also structurally distinct: rather than splitting assault (threat) from battery (contact) the way Louisiana, Oklahoma, and Nevada do, or folding contact into a graded assault scheme the way Ohio/Alabama/Kentucky/Oregon/Utah do, Iowa's single, largely ungraded assault definition covers both the threat and the contact within the very same subsection. Arkansas is the most fully built-out assault/battery split found in this project: it keeps a genuinely separate, independently numbered three-degree assault ladder (all misdemeanors, no touching required) running alongside a separate three-degree battery ladder (all felonies, actual injury required), at the same time. This surfaced a significant, multi-entry citation-index error: the project's underlying database had every one of Arkansas's numbered assault-degree slugs pointing to the BATTERY statutes instead (a real substantive mismapping, not a citation-number typo), and separately had "assault in the third degree" pointing to what is actually Arkansas's FIRST degree assault statute; all four entries were corrected after independently confirming the text of both full statutory ladders. Arkansas also has a rare three-tier homicide structure (capital murder, the only death-eligible tier, sits above first degree murder, which holds the state's general felony-murder rule) and a genuine, dedicated three-degree domestic battering statute separate from both its assault and battery ladders. Mississippi also has a rare three-tier homicide structure, but its felony murder rule is genuinely INVERTED from Arkansas's (and from almost every other state surveyed): Mississippi's list of violent felonies (rape, kidnapping, burglary, arson, robbery, sexual battery, felonious child abuse) is specifically EXCLUDED from first degree murder's felony-murder path and instead escalates straight to capital murder, while first degree murder catches only the felonies left off that list, the opposite of the usual pattern where the worst felonies land in the top general-murder tier. Mississippi's assault provisions ("simple assault," "aggravated assault," and its domestic violence tiers) are all defined within one single mega-statute (§97-3-7); a genuine mismapping in the underlying citation index had "assault with a deadly weapon" pointed at simple assault's negligent-injury misdemeanor subsection rather than aggravated assault's intentional felony-level weapon subsection, corrected here. Kansas is the third state surveyed, after Arkansas and Nevada/Louisiana/Oklahoma, with genuinely separate assault (no touching) and battery (touching) statutes, and it hit the exact same citation-index failure mode found in Arkansas: every numbered "assault" slug pointed to the BATTERY statute instead of the real, separately-numbered ASSAULT statute, corrected here. Kansas also has an unusually elegant felony-murder/manslaughter design: both statutes cross-reference the same defined term, "inherently dangerous felony," from opposite directions, a death during one of those felonies is felony murder, and a death during any OTHER felony is manslaughter, leaving no structural gap or overlap between the two. New Mexico is the fourth state surveyed with genuinely separate assault and battery statutes, and it reproduced a partial version of the same citation-index failure mode found in Arkansas and Kansas: "assault with a deadly weapon" and "assault in the second degree" were both pointed at New Mexico's BATTERY statute instead of the real, separately-numbered ASSAULT statutes, corrected here after independently confirming the actual subsection text. New Mexico also folds premeditated killing, felony murder (during ANY felony, not an enumerated list), and depraved-mind killing into a single first degree murder statute, all leading to the same capital felony classification, and has a distinctive repeat-offense escalation for armed robbery where a second or subsequent offense jumps straight to a first degree felony. Puerto Rico is the first U.S. territory added to this expansion, and its 2012 Código Penal (Ley 146-2012) required a genuinely different sourcing approach than any state surveyed: it is written in Spanish, structured along civil-law lines, and sentences by a fixed determinate term (e.g. 99 years for first degree murder, 50 for second degree) rather than an indeterminate range or felony-class system used everywhere else in this project. Puerto Rico folds felony murder directly into first degree murder via a specific enumerated felony list, the same structural choice as several states surveyed, but is the only jurisdiction so far to split the voluntary/involuntary manslaughter distinction across two differently-named statutes: "asesinato atenuado" (attenuated murder, the heat-of-passion analog) and "homicidio negligente" (negligent homicide). It does not use numbered assault degrees at all, grading its "agresión"/"agresión grave" statutes purely by resulting injury severity, and has no separate battery statute, the same unified structure found in Indiana, Wisconsin, and Iowa. Its domestic violence law (Ley 54-1989) and DUI/drug possession laws (Ley 22-2000 and Ley 4-1971) live entirely outside the penal code, and Puerto Rico is the only jurisdiction surveyed where a first DUI offense is classified as a felony by default rather than a misdemeanor. Because the official LexJuris and OSLPR sites were not reliably fetchable directly, every Puerto Rico entry in this pass was sourced via Justia/LexJuris research aggregation rather than a direct statute-site read, and the deadly-weapon-assault entry specifically could not be confirmed to subsection-level detail, so it is marked low confidence pending a closer follow-up read. Nebraska was sourced almost entirely via direct fetch from `nebraskalegislature.gov`, the official state legislature site, which proved reliably fetchable for essentially every statute needed (a contrast with several recent states where direct fetch failed and WebSearch-aggregated Justia snippets were the fallback). Nebraska's felony-murder rule folds into first degree murder via an enumerated list that unusually includes hijacking of a public or private means of transportation alongside the more common robbery/arson/kidnapping/burglary/sexual-assault paths. Its base assault-in-the-third-degree statute has a genuinely distinctive mutual-combat carve-out: the offense downgrades from a Class I to a Class II misdemeanor specifically when it happens during a fight entered into by mutual consent, not seen quite this way in any other state surveyed. Nebraska keeps both robbery and burglary completely ungraded, no degree split at all for either, the same pattern Nevada uses for robbery; its burglary statute still requires an actual breaking. Its theft statute carries the same kind of repeat-offense escalation trap found in Arkansas and Kansas. Nebraska's DUI statute uses a distinctive "Class W misdemeanor" classification specific to traffic offenses, not seen in any other state surveyed, before escalating to ordinary misdemeanor and then felony classes for enhanced-BAC or repeat offenses. ## 12. Data Quality Flags

### Known limitations

**Criminal charges database is synthesized, not direct statute pulls.**
The charges in `shared/criminal-charges.ts` are based on Model Penal Code patterns, not individually pulled from each state's legislature. Generated statute codes are used for consistency in the AI guidance system. Statute citations from this database should not be cited as authoritative without cross-referencing against the relevant state's official code. Tier 3 (OpenLaws) provides a live verification fallback for any citation that appears in AI guidance output.

**Diversion program data changes frequently.**
Eligibility criteria, operating hours, phone numbers, and even program existence change often. The quarterly URL check catches dead links but cannot verify whether the program details are still accurate. Diversion program entries should be re-verified against the source court or prosecutor's office at least annually.

**Immigration guidance requires accelerated review.**
Immigration law and enforcement policy change rapidly. `immigration-guidance.tsx` is on a 6-month review cycle (next due 2026-09). A dated policy alert for USCIS memo PM-602-0199 (adjustment of status policy change, May 22, 2026) was added in May 2026. Full line-by-line review of the page body remains outstanding. The new `after-deportation.tsx` page was added May 2026 and is due for its first review by November 2026.

**BJS analytics integration is in progress.**
References to Bureau of Justice Statistics (BJS) API integration for crime statistics and NCVS/NIBRS data appear in the codebase but are not yet live. Do not cite these as active data sources.

**Attorney review not yet completed.**
Platform content has not been formally reviewed by a licensed attorney as of March 2026. A legal review pass is recommended before public launch, particularly for the immigration guidance and collateral consequences pages.
