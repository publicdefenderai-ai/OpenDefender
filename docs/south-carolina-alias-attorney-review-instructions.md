# South Carolina title-alias attorney review

This worksheet contains the 38 South Carolina title aliases that are currently withheld from advocates. No alias is currently selectable.

## How to complete it

1. Open the CSV worksheet in Excel, Google Sheets, or another spreadsheet program.
2. Review one row at a time.
3. Open the link in the officialCodeUrl column. The page is the South Carolina Legislature Code of Laws. Use the citation column to find the exact section.
4. Pay special attention to the subsection shown in the subdivision column.
5. Decide whether the proposed alias describes the same offense as the catalogLabel.
6. Fill in all four blank columns:
   - decision: enter exactly approve or reject
   - reviewer: attorney’s name
   - reviewedAt: review date in YYYY-MM-DD format
   - note: brief rationale, including the section/subsection reviewed
7. Return the completed CSV file in this chat. Do not edit the chargeId, catalogLabel, proposedAlias, citation, subdivision, or officialCodeUrl columns.

A complete attorney review must contain a decision for every row. Rejected or uncertain mappings should be marked reject; they will remain withheld. Approved mappings will still be checked against the official title, exact citation, and required subdivision before publication.
