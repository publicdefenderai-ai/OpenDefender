The harder part of your problem isn't finding statute text—it's reliably mapping a charge description to the right citation. Let me cover both.
California
The authoritative source is California Legislative Information (leginfo.legislature.ca.gov), run by the Legislative Counsel. It's the official codified text of all 29 California Codes, including the Penal Code, Vehicle Code, Health & Safety Code, etc. It's the source of truth, though its programmatic access is awkward.
For an actual API over California code, Open Legal Codes (openlegalcodes.org) is worth a look—it's a free API and MCP server with no signup or key, and it pulls from publishers including California Leginfo across 37,000+ jurisdictions, returning real statute text with permalink URLs users can verify themselves. Be aware it's run by a private company (TIDY) and fetches/caches on demand, so you'd want to spot-check freshness. Openlegalcodes
There's also california.public.law, which is a clean, current, readable mirror of the codes. Avoid the older tylerpearson/california-laws-api and calilaws.com project—its data dump is from 2015 and is stale for anything where the statute has since been amended or renumbered.
New York
New York is actually better-served than California here. The NY Senate runs Open Legislation (legislation.nysenate.gov), an official, open-source service with a documented JSON REST API. You sign up for a free API key, and it exposes bills, resolutions, and the Consolidated Laws. Its Laws API identifies each law by a three-letter code—for the Penal Law that's PEN, so you can pull statute structure and text directly. The browsable version lives at nysenate.gov/legislation/laws/PEN. This is the one I'd build against for NY. NysenateNysenate
Cross-state / fallback
Cornell's Legal Information Institute (law.cornell.edu/states) is free and reputable and gathers state-by-state constitutions, statutes, judicial opinions, and regulations for all fifty states plus D.C. and the territories. Justia (law.justia.com) and FindLaw offer similar free statute browsing. None of these have a clean public API the way NY does, but they're good for human verification and for states beyond CA/NY as you expand. Cornell Law School
The part that will actually bite you: the matching problem
Pulling verified statute text is the easy half. The hard half is that charge descriptions in your list—especially if they come from arrest records, court dockets, or rap sheets—are rarely clean statute citations. They're often abbreviated, locally idiosyncratic, or attached to internal agency codes rather than the Penal Code section. A label like "PC 459" or "Burglary 2nd" has to be resolved to the correct subsection, and the same English description can map to different sections depending on degree, year, or amendment history.
A few things help with that:
The official sources above let you verify a candidate citation by confirming the statute's text matches the charge's substance—this is the step that turns a guess into a "verified" citation. Build your pipeline so every match is confirmed against retrieved statute language, not just string-matched against a description.
If your charge data carries standardized offense codes (many criminal-justice datasets include FBI NIBRS/UCR offense codes, or state-specific charge-code tables like California DOJ's offense code tables used in CORI/RAP sheets), those crosswalks are more reliable to map than free-text descriptions. It's worth checking whether your source data includes them.
Be cautious about point-in-time accuracy. A charge from 2014 may cite a section that's since been amended, renumbered, or repealed (California's Prop 47 reclassifications are a classic example). Verified citation work usually means matching to the statute as it existed on the offense date, which most free sources don't make easy—they show current text. LegiScan's bulk session-law datasets (JSON/XML/CSV for all states) can help reconstruct historical versions if that matters for your use case.
One honest caveat: none of these are a turnkey "charge description → guaranteed-correct citation" service. They're authoritative text sources you assemble into a verification layer. The free options will get you accurate statute text; the matching logic and the human or rules-based confirmation that a description corresponds to a specific section is the work you'd own.
